# Spec Delta

## Purpose

NEO と noReita の外部パレットを専用の作業領域へ切り替え、描画内容や利用者の倍率を保って通常表示へ戻せるようにする。背景ページの操作抑止と復帰、画面サイズ変更、NEO の Float との共存を両テーマで保証する。

## ADDED Requirements

### Requirement: 外部パレットを含む作業領域の専用表示

システムは、eda と monoreita の両テーマで、FIT により NEO と外部パレットをブラウザーの表示領域を占有する専用表示へ切り替えなければならない（MUST）。外部パレット先頭の既存 `FIT!` fieldsetの同じ位置に、通常表示では開始ボタン、専用表示では「通常表示に戻る」ボタンを表示しなければならない（MUST）。専用の上部ツールバー、その空き領域、重複する解除操作を設けてはならない（MUST NOT）。FIT中は同fieldsetをパレット上端にsticky配置し、解除操作へ常に到達可能でなければならない（MUST）。ブラウザー自体の全画面切り替えを要求してはならない（MUST NOT）。

#### Scenario: 専用表示を開始する

- **GIVEN** NEO v1.8.8 の描画画面が初期化済みで、通常ページに描画領域と外部パレットがある
- **WHEN** 利用者が FIT を開始する
- **THEN** NEO と外部パレットが専用の作業領域に表示され、掲示板のヘッダーなどは背後に隠れる
- **AND** 元の `FIT!` fieldsetで開始ボタンが「通常表示に戻る」ボタンへ切り替わり、独立した上部ツールバーや空き領域はなく、ブラウザー自体は全画面表示へ切り替わらない

#### Scenario: 同じFIT操作欄で通常表示へ戻る

- **GIVEN** 専用表示で外部パレット先頭の `FIT!` fieldsetに「通常表示に戻る」ボタンが表示されている
- **WHEN** 利用者がそのボタンをクリック、またはキーボードのEnter／Spaceで操作する
- **THEN** 通常表示へ戻り、同じfieldsetの同じ位置に開始ボタンが再表示される
- **AND** 別の解除ボタンや専用上部ツールバーは表示されない

#### Scenario: 専用表示中に表示領域の大きさが変わる

- **GIVEN** 専用表示を利用している
- **WHEN** ブラウザーの表示領域の幅または高さが変わる
- **THEN** 作業領域と表示用キャンバスが新しい領域に合わせて更新される
- **AND** 解除操作、描画ツール、外部パレットを引き続き操作できる

#### Scenario: 狭い画面と長いパレットを利用する

- **GIVEN** 表示領域が操作部品を一度に並べるには狭い、または低く、外部パレットにも表示しきれない項目がある
- **WHEN** 利用者が専用表示を開始し、作業領域内をスクロールする
- **THEN** 描画ツールとパレットの項目へ到達でき、パレット末尾までスクロールしても先頭の `FIT!` fieldsetが上端に残り、解除ボタンをクリック・キーボードで操作できる
- **AND** 到達できない位置へ操作部品が隠れたり、描画アプリ全体の縮尺変更で表示を無理に収めたりしない

### Requirement: FIT の終了理由に応じた倍率の扱い

システムは、FIT の開始・専用表示中の領域変更で利用者が選択した倍率を変更してはならない（MUST NOT）。利用者が通常の解除操作を実行した場合に限り、倍率を 1 倍へ戻さなければならない（MUST）。Float への切り替えや開始失敗の復旧では、FIT 側で倍率をリセットしてはならない（MUST NOT）。表示領域に応じた描画範囲の制限後も、NEO のズームとスクロールを引き続き利用できなければならない（MUST）。

#### Scenario: ズーム状態を保持して開始とリサイズを行う

- **GIVEN** 利用者が NEO の倍率を 2 倍へ変更している
- **WHEN** FIT を開始し、専用表示中の表示領域を変更する
- **THEN** 開始後と領域変更後も倍率は 2 倍であり、1 倍に戻されない
- **AND** 専用表示中でもズームとスクロールを操作できる

#### Scenario: 通常の解除操作で倍率を1倍へ戻す

- **GIVEN** 利用者が FIT の専用表示で NEO の倍率を 2 倍へ変更している
- **WHEN** 利用者が専用表示内の通常の解除操作を実行する
- **THEN** 通常表示へ戻り、倍率は 1 倍になる
- **AND** 解除後もズームとスクロールを操作できる

#### Scenario: 小さい画像を原寸表示する

- **GIVEN** 画像の縦横が描画可能な表示領域より小さく、利用者が 1 倍表示を選択している
- **WHEN** FIT を開始・解除する、または専用表示中に領域が広がる
- **THEN** 倍率は 1 倍のままで、画像は空き領域を埋めるために引き伸ばされない

### Requirement: 描画データと編集操作の保持

システムは、FIT の表示切り替えや領域変更だけを理由に、画像の原寸、各レイヤーの画素、表示・非表示状態、編集履歴を変更してはならない（MUST NOT）。専用表示内の描画・編集結果は解除後も保持し、Undo と Redo を継続して利用できなければならない（MUST）。

#### Scenario: 表示変更だけでは作品を変更しない

- **GIVEN** 両レイヤーに画素があり、一方を非表示にした状態で、画像の寸法と編集履歴が記録されている
- **WHEN** FIT の開始、表示領域の変更、解除を行う
- **THEN** 画像寸法、両レイヤーの画素、表示状態、履歴が各表示変更の前後で一致する
- **AND** 新しい表示領域にも描画内容が再描画される

#### Scenario: 専用表示内の編集を通常表示へ引き継ぐ

- **GIVEN** 専用表示内で描画または編集した
- **WHEN** 専用表示を解除し、直前の編集に Undo と Redo を行う
- **THEN** 解除直後には最新の編集結果が残っている
- **AND** Undo でその編集を戻し、Redo で再適用できる

### Requirement: 背景ページと作業領域の入力分離

システムは、専用表示中に背後の通常ページへスクロールやキーボード操作が及ばないようにしなければならない（MUST）。作業領域内のスクロール、入力欄、NEO の既存のショートカットと確認操作を妨げてはならない（MUST NOT）。

#### Scenario: 背後のページを操作できない

- **GIVEN** 通常ページにフォーカス可能なリンクやフォームがあり、専用表示を開始した
- **WHEN** 利用者がホイールやキーボードで操作する
- **THEN** フォーカスは専用表示内へ移り、背後のページはスクロール・フォーカス移動・入力の対象にならない
- **AND** 専用表示の解除操作をキーボードで利用できる

#### Scenario: NEO と外部パレットの操作を維持する

- **GIVEN** 専用表示内の NEO または外部パレットを操作している
- **WHEN** 利用者がスクロール、文字入力、NEO のショートカットや確認ダイアログを利用する
- **THEN** 既存の操作が機能し、FIT のキー処理に横取りされない
- **AND** Escape を押しただけでは FIT を解除しない

### Requirement: 利用者による解除と通常ページへの復帰

システムは、利用者が専用表示を解除したとき、通常のレイアウトと開始前の背景操作状態、ページ位置、フォーカスへ戻さなければならない（MUST）。復帰は FIT が行った変更だけを取り消し、操作を繰り返しても状態を蓄積してはならない（MUST NOT）。

#### Scenario: 元のページ位置とフォーカスへ戻る

- **GIVEN** ページをスクロールした位置から FIT を開始している
- **WHEN** 利用者が専用表示内の解除操作を実行する
- **THEN** 作業領域が通常のレイアウトへ戻り、背後の操作抑止が開始前の状態へ戻る
- **AND** 開始前のページ位置とフォーカスへ戻る
- **AND** 保存位置が画面サイズ変更で無効になった場合は有効なスクロール範囲に収まり、フォーカス先がなくなった場合は通常表示の FIT 開始操作へ戻る

#### Scenario: 切り替えと開始要求を繰り返す

- **GIVEN** 通常表示と専用表示を複数回切り替え、既に専用表示の間にも FIT 開始を要求する
- **WHEN** 利用者が各専用表示を解除する
- **THEN** 各回の開始前のページ状態へ戻り、専用表示中の重複要求で復帰位置が上書きされない
- **AND** 背景が操作不能のまま残らず、枠の寸法や操作状態が累積的にずれない

### Requirement: 初期化前に専用表示へ入らない

システムは、NEO の読み込み・描画画面の初期化と必要な表示更新機能が利用可能になる前に専用表示へ入ってはならない（MUST NOT）。開始できない操作で背景を抑止したり、FIT 状態を変更したり、例外を発生させてはならない（MUST NOT）。

#### Scenario: 読み込み前と完了後に FIT を操作する

- **GIVEN** ページは表示済みだが、NEO の読み込みまたは初期化が完了していない
- **WHEN** 利用者が FIT の開始を要求する
- **THEN** 通常表示と背景の操作状態が維持され、例外が発生しない
- **AND** 初期化完了後は同じページで改めて FIT を開始でき、過去の開始要求が勝手に実行されない

### Requirement: NEO の Float を優先した表示切り替え

システムは、NEO の Float の操作・確認・標準動作を変更してはならない（MUST NOT）。Float 開始時は専用表示を解除して Float を優先し、背後のページへフォーカスを引き戻してはならない（MUST NOT）。Float 終了後に専用表示を自動再開してはならない（MUST NOT）。

#### Scenario: 専用表示から Float へ切り替える

- **GIVEN** FIT の専用表示を利用し、NEO の倍率を 2 倍へ変更している
- **WHEN** 利用者が NEO の Float を開始し、確認を承認する
- **THEN** FIT のレイアウトと背景操作抑止が解除され、NEO 標準の Float 表示を利用できる
- **AND** フォーカスが背後のページへ引き戻されない
- **AND** FIT 側の倍率リセットは行われず、NEO 標準の Float 処理を上書きしない
- **AND** Float 終了後は通常表示となり、専用表示へ勝手に戻らない

#### Scenario: Float の確認をキャンセルする

- **GIVEN** FIT の専用表示から NEO の Float を開始しようとしている
- **WHEN** 利用者が NEO の切り替え確認をキャンセルする
- **THEN** 専用表示とその操作状態、選択した倍率が維持される

#### Scenario: Float 中に FIT 開始を要求する

- **GIVEN** NEO の Float を利用している
- **WHEN** FIT の開始を要求する
- **THEN** Float 表示が維持され、専用表示のレイアウトや背景操作抑止が追加されない
