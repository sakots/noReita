# エラーの調査手順

noReitaは本番画面へPHPの内部パス、例外メッセージ、スタックトレースを表示しません。内部エラーが発生すると、利用者には発生日と照合用IDを表示します。

```text
発生日: 20260728 / エラーID: 20260728123456-a1b2c3d4
```

## 設置者が確認する場所

FTPソフト、サーバーのファイルマネージャー、またはSSHで次のログを確認してください。

```text
noreita/errorlog/error-YYYYMMDD.log
```

管理者としてログインできる場合は、管理画面の`[エラーログ]`からも確認できます。日付、記録種別、HTTP 4xx/5xxで絞り込め、該当日の新しい100件を表示します。ログファイルそのものは引き続きHTTP公開されません。

管理画面から成功した状態変更は、エラーログとは独立した次の監査ログへ`admin-audit`として記録されます。

```text
noreita/auditlog/audit-YYYYMMDD.log
```

管理画面の`[監査ログ]`からも確認できます。ログイン・ログアウト、投稿の編集・削除・非表示・再表示、テーマ設定、一時画像の削除・整理について、操作種別と件数だけを残します。投稿番号、画像名、パスワード、IPアドレス、テーマ設定値は記録しません。更新前に`errorlog/`へ記録された既存の`admin-audit`は移動せず、従来のエラーログ画面から確認できます。

1ファイルが既定の5 MiBへ達すると、`error-YYYYMMDD.1.log`から順にローテーション
します。既定では1日5ファイルまでとし、上限到達後はnoReitaのログを増やさず、要約を
レンタルサーバー標準のPHPエラーログへ送ります。

ログは1行につき1件のJSONです。各行には検索しやすい`date`（`YYYYMMDD`）と
`error_id`が独立した項目として記録されます。まず日付でログファイルや行を絞り込み、
利用者から伝えられた`error_id`を検索してください。ほかに発生日時、PHPバージョン、
リクエストパス、例外の種類、内部ファイルと行番号、スタックトレースが含まれます。

```json
{"timestamp":"2026-07-28T12:34:56+09:00","date":"20260728","error_id":"20260728123456-a1b2c3d4"}
```

```bash
grep '20260728123456-a1b2c3d4' noreita/errorlog/error-20260728.log
```

POSTデータ、Cookie、セッション全体は記録しません。管理パス、CSRFトークン、Misskeyトークンなど、実行時に把握できる秘密値は`[REDACTED]`へ置換します。ただし、投稿本文や独自プラグインが例外メッセージへ埋め込んだ情報まで完全に判別できるとは限らないため、ログ全体を公開の場所へ貼らないでください。

## ログが作成されない場合

- `errorlog/`がPHPから書き込み可能か確認してください。初期設定の権限はディレクトリ`0700`、ログファイル`0600`です。
- `errorlog/.htaccess`がアップロードされているか確認してください。
- 監査ログの場合は、同様に`auditlog/`の書き込み権限と`auditlog/.htaccess`を確認してください。
- 書き込みに失敗した場合、要約はレンタルサーバー標準のPHPエラーログへ送られます。
- `.htaccess`自体の構文エラー、PHPが起動する前のエラー、`error_handler.inc.php`の欠落はアプリのログへ記録できません。この場合はサーバー管理画面のエラーログを確認してください。

`errorlog/`または`auditlog/`へブラウザーからアクセスした場合は403になるのが正常です。ログを確認するためにアクセス拒否設定を解除しないでください。

## Warningの確認

処理を継続できるWarningやNoticeは公開画面へ表示せず、ログへ記録します。この場合は画面にエラーIDが表示されないため、発生日時と操作内容を手掛かりに該当時刻のログを確認してください。

ログはアクセス時に確率的に整理され、既定では更新から30日を過ぎたものを1回20件まで
削除します。当日分、書き込み中のログ、命名規則に一致しないファイルは削除しません。

保持期間、1ファイルの容量、1日あたりのファイル数は`config.local.php`で変更できます。監査ログは`audit_log`で別に設定し、既定では365日保持します。

```php
<?php
return [
  'error_log' => [
    'retention_days' => 30,
    'max_bytes' => 5242880,
    'max_files_per_day' => 5,
  ],
];
```

```php
<?php
return [
  'audit_log' => [
    'retention_days' => 365,
    'max_bytes' => 5242880,
    'max_files_per_day' => 5,
  ],
];
```
